# GlowFluid 运维与回滚

控制中心「高级 → 辉光参数」分区、质量切换、空闲行为和回滚路径的操作说明。视觉偏差清单见 `glow-fluid-deviations.md`。

## 1. 参数区与预设

- 位置：控制中心 → 高级页 → 「辉光参数」分区（第 7 个分区按钮）。
- 参数：辉光强度、尾迹宽度 (px)、停留时间 (s)、余辉强度、热点增白、跟随速度、颗粒感（滑柱）；主颜色 / 冷却颜色（编辑框 + 色板 + 系统取色器，冷却颜色留空时按参考实现的色相旋转从主色派生）；模拟质量（低/中/高）；点击爆发开关。
- 「恢复余烬预设」：把全部 Glow 字段恢复为截图预设（#7c3aed / #a855f7 / 0.3 / 3px / 0.3s / 0.5 / 0 / 1 / 0.15 / high）。IPC 的配置补丁是单路径的，因此按钮按字段依次发送；BA 特效参数和已保存的 FX 预设完全不受影响——Glow 拥有独立命名空间。
- 持久化：Glow 参数与 `effectStyle` 随主配置写入（schema 21），重启后恢复。FX 预设（`FxProfileStore`）只保存 `EffectsConfig`，加载预设不会改写样式或 Glow 参数；切换 BA↔Glow 也不会丢失任何一侧的设置。以上均有配置层测试覆盖（`glow_settings_survive_style_switch_and_fx_profile_load`）。

## 2. 质量切换

- 质量补丁经 Host 实时生效：`GlowFluidPipeline::setQuality` 标记重分配，下一帧 `step` 时释放旧目标并按新档位（low 96/384、medium 128/576、high 160/768，含宽高比与交换链分辨率 shrink）重建全部 ping-pong 目标与 bloom 链。
- 重分配在渲染线程内完成；若创建失败，管线标记失败并停止绘制，样式降级（见回滚），主进程不中断、不崩溃。
- 切换不丢失当前帧内容语义之外的任何东西：染料场会随重分配清零（新档位分辨率不同，无法迁移），这是预期行为。

## 3. 空闲行为与性能

- 休眠条件（与参考实现一致）：最后一个指针活动超过 `linger*1.2+0.9` 秒（余烬预设 1.26 秒）**且** emitter 速度低于 1 px/s。满足后清空模拟场、提交一帧全透明画面，随后 `needsFrame` 转假，Host 渲染循环跳过渲染与 Present，进入空闲。
- 唤醒：新的指针样本把 emitter 吸附到该位置（不产生假轨迹），渲染循环恢复。
- **已测**：WARP 渲染器测试验证「移动出迹 → 停 1.26s → needsFrame=false 且末帧全透明 → 唤醒只点亮新路径」（`glow_fluid_renderer` 套件）。
- **未测（本机无交互桌面）**：静止 5 秒以上 CPU/GPU 占用与原版空闲基线的实测对比。机制上空闲期不提交帧，预期与 BA 空闲基线一致，但未取得实测数据。

## 4. 回滚路径

按影响范围从轻到重：

1. **切回 BA**：控制中心基础页「特效样式」选「蔚蓝档案点击特效」。Host 实时应用，`setGlowStyleEnabled(false)` 会立即丢弃 Glow 累积场，BA 特效与全部既有设置不受影响。这是日常回滚路径。
2. **管线失败降级**：流体管线创建或运行失败时，`GlowFluidRenderer` 回落到加法混合占位渲染（不再有流体视觉，但仍有拖尾），Host 继续运行。创建失败时样式整体停用（画面透明），BA 路径不受影响。
3. **配置回滚**：Glow 参数随主配置持久化；如需整体回退到无 Glow 的版本，使用安装器降级即可（Glow 只在 schema 21 存在，旧版本会忽略未知字段并保留 BA 行为——严格解析下旧版本会拒绝 schema 21 配置文件，此时需先切回 BA 样式再降级）。

## 5. 已知限制

- 实机视觉（贴手程度、消散手感、白底亮度）未验证，见偏差清单第 1、3 条。
- 压力求解 20 次 Jacobi 对低频发散收敛慢，与参考实现一致；快速大范围划动时可能出现轻微体积伪影。
- 跨屏流体不连续（每屏独立模拟场）；第一版仅承诺单主屏 SDR。
